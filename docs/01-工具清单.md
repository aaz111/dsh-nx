# 工具清单（55 个）

单位统一 **mm / 度 / kg**，坐标一律是模型空间 `[x, y, z]` mm，**Z 向上**，原点在 (0,0,0)。

## 通用约定

- **点/轮廓一律是扁平数字数组**：一个点写 `at: [40, 25, 12]`；多个点不要嵌套，写成
  `edges: [0,0,6, 100,0,6, 100,70,6, 0,70,6]`（每 3 个数一个点）。嵌套数组会被参数层拒绝
  （`invalid arguments: "edges" must be an array`）。轮廓同理：`profile: [0,0, 80,0, 80,50, 0,50]`（每 2 个数一个点）。
- **选体**（`bodies`/`target`/`tools`/`component`）可用：索引 `0`、`-1`（最后一个）、名字 `Body01`，
  多个用逗号或数组 `"0,2"`；`bodies: "all"` 表示全部（片体件导 STL 必须用它）。
- 失败会抛错并**不做部分回滚**（建模是累积的），所以每步之后用 `nx_measure` 核对方位/体积。

## 1. 会话与文档

| 工具 | 参数 | 说明 |
|---|---|---|
| `nx_status` | — | 桥接与 NX 会话健康状态：pid、NX 版本、已打开 part、可用命令。**每个任务先调它** |
| `nx_session` | `action` = status / stop / restart | 重启 NX 会话（改完 python 必须做，约 20 s）。**restart 会丢失未保存的模型** |

| `nx_info` | — | 当前 part 的身份、单位、图纸页（名称/尺寸/比例/视图）、可用标准视图 |
| `nx_save` | `path`、`overwrite` | 不传 `path` 存回原文件；传 `path` 则另存 |

## 2. 实体建模

| 工具 | 参数 | 说明 |
|---|---|---|
| `nx_primitive` | `kind`=block/cylinder/cone/sphere、`at`、`length`/`width`/`height`、`diameter` 或 `radius`、`baseDiameter`/`baseRadius`、`topDiameter`、`axis` | 加基本体。block 从 `at` 角点起；cylinder/cone 从 `at` 底面圆心沿 `axis`（默认 +Z）；sphere 以 `at` 为心 |
| `nx_extrude` | `profile`、`height`（默认 10）、`plane`=xy/xz/yz、`base`、`draft` | 拉伸闭合轮廓；`draft` 是拔模角（度），负数向外 |
| `nx_revolve` | `profile`、`angle`（默认 360）、`plane`（默认 xz）、`base`、`axis`、`axisPoint` | 旋转成回转体；`profile` 每对数是 `(半径, 轴向高度)` |
| `nx_polygon` | `profile`、`plane`、`base` | 只画闭合多边形曲线，不生成实体 |
| `nx_boolean` | `op`=unite/subtract/intersect、`target`、`tools` | 布尔；`tools` 可一次给多个工具体 |
| `nx_fillet` | `radius`（必填）、`edges`、`bodies` | 圆角。半径过大会报 `blend faces overlap`，此时**分几次、每次少量边** |
| `nx_chamfer` | `distance`（必填）、`edges`、`bodies` | 等距倒角；自动只用直线边重试并报告用了多少条 |
| `nx_hole` | `target`、`at`、`diameter` 或 `radius`、`depth`、`axis`、`native`、`type`=simple/counterbore/countersink、`counterboreDiameter`、`counterboreDepth`、`countersinkDiameter`、`countersinkAngle` | 孔。`native:true` 提交真实 Hole 特征（需平面放置面），`type` 让它成为**沉头孔**（counterbore）或**锥沉头孔**（countersink，角度是锥的全角，默认 90 度）；否则圆柱切除。**从顶面往下打孔要给 `axis:[0,0,-1]`** |
| `nx_thread` | `target`、`at`、`diameter`/`radius`、`standard`、`size`、`external`、`type`=symbolic/detailed、`length`、`engage`、`handedness` | 真实 Thread 特征。规格表读 NX 自己的 `NX_Thread_Standard.xml`（31 个标准），省略 `size` 时按实测圆柱直径自动选型 |
| `nx_shell` | `target`、`thickness`（默认 1）、`tolerance`（默认 0.01）、`openFaces` | 抽壳；`openFaces` 用面索引或面上一串点 |
| `nx_transform` | `target`、`mode`=translate/rotate/mirror、`direction`/`distance`、`axis`/`axisPoint`/`angle`、`normal`/`planePoint`、`keepOriginal` | 移动体（提交真实 Move Body / Mirror Body 特征） |
| `nx_pattern` | `target`、`mode`=linear/circular、`count`、`pitch`、`direction`、`angle`、`axis`、`axisPoint` | 实体阵列（Pattern Geometry 特征） |
| `nx_expression` | `action`=list/set/create/delete、`name`、`formula`/`value`、`filter`、`limit` | 读写驱动表达式，改值后模型重算；支持公式引用（`plate_x*2`） |
| `nx_sync_face` | `op`=move/offset/pull/resize、`face`（面上一点，或 `{index\|radius\|diameter\|z\|area}`）、`vector`、`distance`、`diameter`、`body` | **同步建模**改一个面，无需草图：`move` 平移到指定方向，`offset` 沿面法向偏置，`pull` 拖动面，`resize` 改圆柱面直径（孔壁/凸台/圆角）。回读 `volumeBefore` 与 `volumeChange` |
| `nx_sync_region` | `face`、`faces`、`heal`（默认 true）、`body` | **删面并愈合**：删圆角、小凸台、孔壁等，NX 用相邻面补洞；补不上时返回 NX 原始错误。**面替换（ReplaceFace）在本会话会挂死 worker，未暴露** |
| `nx_tube` | `path`（点列）、`outerDiameter`/`diameter`、`innerDiameter`、`tolerance` | 沿折线扫出真实 Tube 特征：实心杆或空心管。默认公差 0.1 mm（更紧会报 `Tolerance error`）。生成独立实体，要并入实体用 `nx_boolean` |
| `nx_csys` | `origin`、`xDirection`、`yDirection` | 建笛卡尔坐标系（Z 由右手定则），提交真实基准坐标系 |
| `nx_rib` | `path`、`face`/`faces`、`height`（默认 8）、`width`（默认 3）、`target` | 轮廓筋：曲线长在面上、按高度与厚度长出，再并进目标体。面按距离与面积的综合排序取前 4 个逐个试提交，可用 `face:{index: N}` 精确指定 |
| `nx_pattern_feature` | `features`（索引或名字）、`countX`、`countY`、`pitchX`、`pitchY` | **特征**阵列（孔/凸台/凸垫），不是实体阵列；目前只做线性 |

## 3. 曲线与曲面

| 工具 | 参数 | 说明 |
|---|---|---|
| `nx_curve` | `kind`=line/arc/circle/spline、`points`（扁平）、`radius`/`diameter`、`axis`、`degree`、`closed` | 直线、三点圆弧、圆、过点样条；返回长度 |
| `nx_surface` | `kind`=through_curves/mesh/extrude、`sections`、`primary`、`cross`、`profile`、`direction`、`distance`、`closed`、`degree` | 片体：放样 2..n 个截面（2 个截面＝直纹面）、主叉曲线蒙皮、沿方向拉片体 |
| `nx_datum` | `kind`=plane/axis/point、`origin`、`normal`、`start`、`end`、`direction`、`length` | 基准平面 / 基准轴 / 基准点 |
| `nx_sketch` | `plane`=xy/xz/yz、`base`、`shapes`、`constrain`、`height`、`extend`、`symmetric`、`cut`、`through` | 在建草图里画 rect/circle/line/polyline（自动水平/垂直/重合约束），可顺手挤出；`cut+through` 贯通减料 |
| `nx_surface_sew` | `bodies`（选择器，如 `"0,1"`）、`tolerance` | 缝合片体成一个体（布尔 unite 对片体无效）；闭合缝合成实体 |
| `nx_thicken` | `bodies`、`thickness`、`secondOffset`、`reverse`、`tolerance` | 片体加厚成实体；`secondOffset` 双侧成壁；tolerance 必须给（默认 0.01） |
| `nx_surface_trim_extend` | `target`、`tools`、`mode`=trim/extend/corner、`distance`、`tolerance` | 片体互剪（until selected）、按距离延伸、做拐角 |
| `nx_surface_nside` | `curves`（≥3 条边界曲线，`trim`、`degree`、`tolerance`） | N 边曲面补洞：封闭边界环一次补成一张面 |

片体没有体积：用 `nx_measure` 的 mm² 面积与包围盒判定；纯片体件 `nx_export stl` 要给 `bodies:"all"`。
曲面闭环流程：`nx_surface` 放样/蒙皮 → `nx_surface_nside` 补洞 → `nx_surface_sew` 缝合 → `nx_thicken` 加厚成实体 → `nx_surface_trim_extend` 修边界。

## 侧栏面板（0.3.0）

侧栏 **NX** 图标 → `main` 面板（key `dsh-nx`）「NX 控制台」：状态卡、打开零件、快捷操作、
最近产物、操作记录；另有独立预览页与「预览」按钮，把当前件（或整个装配）细网格化后
在 3D 视图里看，支持旋转/平移/剖切/线框/透明/轮廓线/包围盒，信息卡会区分「实体（有体积）」
与「片体/开放网格（无体积）」。

面板路由（`lib/panel.js`）：

- `GET /dsh-nx/state`（`?probe=1` 才启动/询问 NX）
- `POST /dsh-nx/action`（15 条白名单命令）
- `POST /dsh-nx/preview`、`GET /dsh-nx/preview-file`（0.02 mm / 8° 细网格，缓存键 `v4-`）

配置：`panel: false` 不注册路由；`outputDir` 默认 `~/.dsh-nx/out`（或 `DSH_NX_OUT`）。
